# 오늘의 연금번호

연금복권720+ 공식 당첨 이력과 자리별 통계, 무작위·통계 학습 기반 번호 추천 앱입니다.

## 자동 갱신

GitHub Actions가 매시 17분·47분(UTC 기준)에 공식 당첨 이력을 수집합니다. 한국시간에도 매시 17분·47분입니다. 예약 실행은 지연될 수 있으며 수동 실행도 가능합니다.

- 데이터: https://hj080719hj-source.github.io/pension-pick/api/history.json
- 상태: https://hj080719hj-source.github.io/pension-pick/api/status.json
- 회차 누락, 중복, 날짜 오류, 과거 번호 변경, 이전 회차로의 회귀는 거부합니다.
- 수집 실패 시 마지막 정상 데이터를 유지하고 실패 상태를 공개합니다. 다음 예약 실행에서 재시도합니다.
- GitHub가 비활성 저장소의 예약 작업을 중지할 수 있으므로 Actions 실행 상태를 정기적으로 확인하세요.
- 이력은 공개 데이터이며 개인정보·계정·구매 데이터는 저장하지 않습니다.

## 앱

`npm ci` 후 `npm run build:toss`로 `.ait` 파일을 만듭니다. 앱은 HTTPS 이력을 읽으므로 회차 갱신 때 다시 배포하지 않아도 됩니다. 토스 콘솔 업로드와 실제 기기 테스트는 별도입니다.

하루 무료 횟수와 보관 번호는 현재 기기의 저장소 기준입니다. 보상형 광고는 보류 상태입니다. 통계 학습 및 과거 당첨번호 제외는 당첨 확률을 높이지 않습니다.

## 검증

`npm test`로 번호 형식, 중복 제외, 학습 모델, 무료 횟수와 데이터 검증을 확인합니다.
